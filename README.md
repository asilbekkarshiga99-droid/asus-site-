# ASUS онлайн-дүкені

## Іске қосу (ұсынылады: сервер арқылы)

1. [Node.js](https://nodejs.org) орнат (18 не одан жаңа нұсқа).
2. `.env.example` файлын `.env` деп көшір де, ішін толтыр (төменде түсіндірілген).
3. Осы папкада терминал ашып жаз:
   ```
   npm start
   ```
4. Браузерде ашу: **http://localhost:3000**

`npm install` керек емес: серверде сыртқы кітапхана жоқ.

> Сайтты `index.html`-ді екі рет басып (`file://`) ашпа, ондай кезде 3D модельдер жүктелмейді.
> Серверсіз де ашуға болады (`python -m http.server`), бірақ онда аккаунт, AI-кеңесші, әкімші панелі өшіп тұрады, ал тапсырыстар мен пікірлер тек сол браузерде сақталады.

## .env баптаулары

| Атауы | Не үшін |
|---|---|
| `ADMIN_EMAIL` | Осы email-мен сайтта **тіркел** (👤 батырмасы), сонда `/admin.html` ашылады |
| `KASPI_PHONE`, `KASPI_NAME` | Тапсырыс берушіге Kaspi аударымының нұсқауы көрсетіледі |
| `ANTHROPIC_API_KEY` | Нағыз AI-кеңесші (Claude). Бос қалса, бұрынғы қарапайым кеңесші жұмыс істейді |
| `AI_MODEL` | Әдепкісі `claude-haiku-5-5` |
| `SITE_URL` | Доменің, SEO тегтеріндегі `example.com` осыған ауысады |
| `COOKIE_SECURE` | HTTPS-те `1` |

## Не бар

- **3D:** Apple стиліндегі скролл-анимация, ноутбук пен PC корпусын бөлшектеу, түс таңдағыш, өнім бетінде 3D, AR («үстеліңе қой»)
- **Каталог:** баға, экран, процессор, видеокарта, жад бойынша кеңейтілген сүзгі
- **Сервер:** тіркелу/кіру, тапсырыс тарихы мен статусы, бағаны сервер өзі есептейді, пікірлер, жазылу, байланыс формасы
- **Әкімші панелі** (`/admin.html`): кірулер, тапсырыстар, ең көп қаралған/сатылған өнімдер, тапсырыс статусын өзгерту
- **Төлем:** Kaspi аударымы (нөмір + тапсырыс нөмірі түсініктемеде). Аударым келгенде әкімші статусты «Төленді» деп қояды
- **AI-кеңесші:** Claude каталог бойынша жауап береді, өнімді батырма етіп көрсетеді
- **SEO:** мета тегтер, Open Graph, Twitter, Product schema, `robots.txt`, `sitemap.xml`
- **Тілдер:** ҚАЗ / РУС / ENG

## Білу керек шектеулер

- **Карта арқылы онлайн төлеу** әзірге жоқ. Ол үшін төлем жүйесімен (CloudPayments, Halyk ePay т.б.) келісім жасап, оның кодын қосу керек. Kaspi Pay QR да Kaspi-дің бизнес келісімін талап етеді.
- **3D модельдер** — санаттың үлгісі (бір ноутбук моделі барлық ноутбукке көрсетіледі). PC корпусының ішкі бөлшектері (видеокарта, RAM т.б.) кодпен салынған.
- **AR:** Android-та Chrome, iPhone-да Safari керек, сайт **HTTPS** арқылы ашылуы тиіс.
- **Деректер** `server/data/db.json` файлында сақталады. Оның көшірмесін (backup) жасап тұр.
- Өнімдерді өзгертсең, `products.js` ішіндегі `defaultProducts` тізімін түзет. Сервер бағаны сол жерден алады. Браузердегі «Өнімдерді басқару» тек сол браузерге әсер етеді.
- Сұраныс жиілігі шектеулі (тіркелу, кіру, тапсырыс, AI), бұл спамнан қорғайды.

## Хостинг

Node.js қолдайтын кез келген хостинг жарайды (Render, Railway, VPS т.б.). Баптауларды хостингтің «Environment variables» бөліміне жаз, `npm start` командасымен іске қосылады. `server/data/` папкасы сақталып тұратын (persistent) диск болуы керек.
